# LingEmbed 2027 — Theories Under Pressure

Workshop website for *Theories Under Pressure: Embedding Linguistic Frameworks in Neural Models* (first workshop, COLING 2027, Macau, 9–14 May 2027).

Site: https://stergioscha.github.io/LingEmbed-workshop/
Research programme: https://stergioscha.github.io/LingEmbed/

The site is a single static page (`index.html` and `style.css`) with no build step. Update the dates, venue and submission link in `index.html` as they are confirmed.
